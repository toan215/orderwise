# Orderwise — Hermes working rules

Orderwise is developed through the **Cortex Hub Conductor**. Roadmap work is tracked as Conductor tasks; workers receive one task each and run in fresh worktrees. Follow these rules when working in this repo.

## Non-negotiable: conductor, never inline

When you pick up a Conductor task (`cortex_task_pickup` / a `cortex_*` task landed in `cortex_task_list`), you are a **conductor**: decompose the work and dispatch to real executors. Do NOT grind a large task inline across many turns and files.

- **Load the `conductor-mode` skill first.** It is the full playbook for decomposing into a Cortex task tree and routing to `cortex_agents`.
- Read `cortex_task_tree_create(guide: true)` before planning a tree — the guide states how to cut work, draw dependencies, and write cold-reader descriptions.
- Check `cortex_agents` before planning. If **no worker is online** to take the tasks you would create, stop and say so instead of queuing work that waits forever.
- The conductor does the surveying, cutting, dispatching and reviewing — **never** the heavy implementation itself.

## Verify before you finish

- Frontend (apps/web): run `pnpm typecheck` (or `pnpm --filter web build`) — both must be clean.
- API (apps/api): `pnpm typecheck` before declaring a backend change done.
- Order lifecycle: hold semantics — `hold()` uses `SELECT ... FOR UPDATE` inside the caller's transaction (no nested interactive transaction); `StockHolding.inventoryId` → `InventoryItem.id`; `stockMovement.shopId` from the inventory row, never `''`.
- Return data AFTER commit: services return `detail()` after the transaction commits so the 201 body isn't empty.

## Tech stack — don't drift

- Workspace: pnpm workspaces (monorepo). Next.js 14 App Router + Tailwind + shadcn/ui (apps/web); NestJS 10 + TypeScript (apps/api).
- Ports: API 4010 (4000 is taken by cortex-api). Web dev proxy rewrites `/api/*` → `API_URL` (default `http://localhost:4010`).
- pgvector: extension name is `vector` (not `pgvector`) in `pgvector/pgvector` image. `EMBEDDING_DIM` must match column `vector(1024)`.
- AI provider: no key → `MockLlmProvider`; key + `LLM_BASE_URL` → `OpenAiProvider`. BullMQ via raw `bullmq`, queue names must not contain `:`.

## Repo boundaries

- `packages/prisma` = schema + migrations + seed; `packages/shared` = RBAC. `apps/api` = backend; `apps/web` = Next.js admin.
- Don't touch files outside the task you were given. If a needed change is in another task's files, note it and leave it — do not silently edit shared surface.
